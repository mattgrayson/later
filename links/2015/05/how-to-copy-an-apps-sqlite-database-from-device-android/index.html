How to copy an app's sqlite database from device android ∞

  1. adb -d shell “run-as com.ministrybrands.shelbynext ls /data/data/com.ministrybrands.shelbynext/files”
  2. adb -d shell “run-as com.ministrybrands.shelbynext cp /data/data/com.ministrybrands.shelbynext/files/default.realm /storage/emulated/legacy/Download/shelbynext.realm”
  3. adb pull /storage/emulated/legacy/Download/shelbynext.realm ~/Desktop
