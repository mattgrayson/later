AdRotate for WordPress ∞

Add and manage the code from the dashboard and show a random banner, or multiple, on your site. The plugin supports groups for banners allowing to tie certain banners to different areas of the website. Easy management from the dashboard allows you to quickly oversee, add and edit banner code. Previewing of banners when editing them. And even some statistical values.
