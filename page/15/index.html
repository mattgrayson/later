RDP H.264/AVC Acceleration up to 60 fps ⇥

On Windows 10/Server 2016 and above, you can enable nearly 60fps connections between clients using H.264, which considerably improves the user experience.

  1. Run gpedit.msc
  2. Go to Computer Configuration -> Administrative Templates -> Windows Components -> Remote Desktop Services -> Remote Desktop Session Host -> Remote Session Environment
    1. Enable Prioritize H.264/AVC 444 Graphics mode for Remote Desktop
    2. Enable Configure H.264/AVC hardware encoding for Remote Desktop
  3. Run gpupdate /force
  4. Run regedit
  5. Create a DWORD(32-bit) key named “DWMFRAMEINTERVAL” under HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations with the value 15 (decimal).
